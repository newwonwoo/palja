# 원본 운세 트리 분석과 첫 구현

기준은 해시 검증된 8자어때 18.2.8 ARM64 AOT다. 원본 실행·실기기 대조는 아직 완료하지 못했다. 원본 바이너리와 분석기 출력은 공개 저장소 밖에 보관한다.

## 원본에서 확인한 범위

|---|---|
| 선택운 5단 | `WoonseTreeLucks`: 시진 `0xa791b0`, 일진 `0xa79260`, 절운 `0xa79310`, 세운 `0xa793c0`, 대운 `0xa79494` |
| 원국 | `WoonseTreeChartPage._buildSajuHeader`, ‘원국’ `0xa7f6a0` |

## 구현·검증한 세부 작업

- [x] 명식 화면에서 운세 트리를 열고 시진·일진·절운·세운·대운과 원국을 함께 표시.
- [x] 선택 날짜·시각 적용 및 저장, 오늘 복귀, 새로고침, 명식으로 뒤로가기 연결.
- [x] ‘운세 보기’가 같은 날짜·시각의 운세 탭을 열고, ‘메모 작성’에서 해당 선택운을 기록·저장하도록 연결.
- [x] 교운 시각이 반환되는 경우 다음 대운 시작 직전까지 이전 대운을 선택. 같은 연도 안의 교운 전후와 정확히 경계인 순간을 검사.
- [x] 시각이 없는 대운은 ‘연도 기준’으로 구분. 마지막 대운을 무기한 연장하지 않으며, 대운 시작 전/정보 없음은 빈 기둥으로 표시.
- [x] 미확인 일주에는 트리를 만들지 않음. 출생 시각 미상과 조회 시각은 별개로 유지.
- [x] 십신·운성·납음·신살 표시 옵션을 적용. 원국 글자와 명식 원본은 유지.
- [x] 단위 테스트 7개 추가, 전체 **251/251** 통과. 트리 조작 **20개**, 기존 궁합/오늘 복귀/탭 순서 **56개** 점검 통과.
- [x] 320/390/800px에서 문서 가로 넘침 없음. 좁은 화면에서는 트리 내부를 좌우로 이동해 마지막 기둥까지 접근 가능.
- [x] 메모의 선택운 보존, 백업 복원, 오프라인 날짜 변경, 출생정보·기존 한 줄 메모 보존 확인.

브라우저 도구가 없어 설치된 Playwright Chromium을 사용했다(`Browser plugin not available`). QA는 `http://127.0.0.1:8851/`, 산출물은 `/tmp/palja-tree-qa/`에 보관한다. 원본 근거와 현재 렌더링의 차이는 아래 미완료 범위로 남긴다.

## 계산의 의미와 남은 차이

선택운에는 기존 독립 절입·시각 계산을 사용하고 원국·대운에는 해당 명식의 저장된 계산 기준을 사용한다. 시간 단위로 교운 경계를 비교한다는 뜻은 **그 교운 시각이 원본 앱과 일치한다는 뜻이 아니다**. 독립 엔진의 대운 시작일 산출도 근사를 포함한다.

- [ ] 원본 실제 화면의 배치·간격·프리셋·단계별 탐색과 전체 조작 대조.
- [ ] 원본 흐름 점수·합화 비중·오행 비율·한난조습의 다층 변화 계산과 연결.
- [ ] 원본 대운 기산법과 정확한 교운 시각의 동일 입력 대조.
- [ ] ‘올해 세운/오늘 일진’ 조회 유형, 원본 선택 유형과 분석 상태 전이 전체 대조.
- [ ] 실기기 뒤로가기·업데이트 보존 검증.

기존 엔진 조사 중 성별·시각이 있는 `2000-01-01` 남성 입력에서 대운 배열이 비는 것을 재현했다. 기존 `calcDaeun`이 같은 연도 절기에서만 순·역방향 인접 절기를 찾고, 이전 해로 넘어가는 경우 초기 경과일 365가 남아 시작 나이 122로 계산된 뒤 100세 필터로 제거된다. 이번 트리는 이 누락을 다른 계산 정책으로 몰래 채우지 않는다. 연도 경계를 포함한 인접 절기 탐색 보완과 원본 대조는 `engine.daewoon`의 남은 작업으로 기록했다.

원본의 구독 안내와 별도 유료 흐름도 존재한다. 새 결제·약관 수락·권한 허용은 수행하지 않았으며, 미연결 항목을 완료로 표시하지 않는다.

후속 반복 10~12에서는 트리 지장간 표시와 조회 유형 저장을 연결하고, 명식표와 교운 경계 판정을 공통화했다. 독립 10대운의 마지막 끝 순간도 명시한다. [후속 근거·검증·남은 차이](original-apk-batch-navigation.md).
