# 오프라인 명리 엔진 독립 교차검증 및 기능 확장 (1.1.1 개발판)

## 정책

8자어때 원본 앱과 결과 대조는 **하지 않습니다**. 본인 앱의 기존 엔진(`src/App.jsx`)과 별도로 만든 천문 절입·한국 표준시 엔진(`src/calendar/precise.js`)을 **같은 출생 입력**에 적용해 두 결과를 나란히 표시합니다. 두 엔진의 일치가 절대 정확성을 보증하지는 않습니다. 추가 규칙은 공개 60갑자·전통 조견표를 독립 구현해 검증합니다.

## 구현 내용

- 명식표에서 `독립 엔진 교차검증`을 열어 시주·일주·월주·연주의 두 결과, 4개 중 일치 개수와 차이가 생길 수 있는 계산 기준을 보여 줍니다. 역법·시각 미확인, 직접 간지 입력, 공통 범위를 벗어난 날짜는 값을 꾸며내지 않습니다. 출력은 읽기 전용이며 저장 데이터를 바꾸지 않습니다.
- 60갑자·30납음, 10갑자 1순 공망, 선택 연도 삼재(연지 기준), 형·파·해·원진·자형 조견표. 납음은 오행 분포의 원래 오행에 합산하지 않습니다. 관계는 조합의 발견일 뿐 합화 성립이나 사건 예측이 아닙니다.
- 두 명식 비교에 일간 합충, 일지·월지 관계와 계산 가능한 동일 기둥 수를 설명과 함께 표시합니다. 보관함에서는 같은 일주·일간·일지·월지·기둥을 기준으로 유사 명식을 로컬 검색합니다. 궁합 점수나 운명 등급을 만들지 않습니다.

## 독립 엔진 경계값 검사

동일 생년월일·시각을 8개 연도 × 3개월 × 3시각 = **72개 합성 사례**로 교차 계산했습니다.

- 비교 가능 72 / 72, 네 기둥 전체 일치 69 / 72.
- **1949-06-18 01:30, 13:30, 23:30** 사례에서 시주만 상이했습니다. 과거 한국 표준시 보정과 자시 경계 차이 때문에 두 엔진이 동일한 시주를 내지 않는 사례가 있음을 노출하는 것이 목적입니다.
- 독립 천문 엔진은 태양 황경 계산, IANA Asia/Seoul 2025b, 윤달, 수정된 현지 시각을 사용합니다. 기존 엔진은 고정 시각 기준과 절입 날짜 중심입니다. 이번 검사는 독립성의 모든 요건이나 역사적 실제 출생시각 정확성을 증명하지 않습니다.

## 유지한 경계

- `src/App.jsx`, Android Native SQLite 구현, 기존 명식·서명키·초기 JSON을 수정하지 않음.
- 저장 구조/스키마 변경 없음. 추가 조견표/비교 결과는 계산된 읽기 전용 화면.
- 삼재·전체 격국·모든 용신/운세 점수, 궁합 점수, 표시 옵션 전체는 별도 작업.
- 실제 Android 기기에서의 업그레이드/재실행/파일선택기는 자동 테스트·브라우저 테스트만으로 검증할 수 없음.
