# 개인 화면 설정 1.1.5

강조 색상, 고딕/명조, 글자 크기 3단계, 명식 카드 3종과 십성·지장간·12운성 표시를 설정에서 선택한다. 명식표와 궁합 비교표에 표시 설정이 적용되며 계산 결과는 변경하지 않는다. 오행의 의미 색상은 유지하고, 배경을 없앤 카드에서는 글자 색으로 오행을 구분한다.

설정은 기존 SQLite 문서의 선택적 `workspace.preferences.appearance` 필드에 저장한다. 해당 필드가 없는 기존 자료는 수정 없이 읽으며, 최초 설정 변경 시 기본값과 함께 추가한다. 기존 명식 ID·입력·메모·그룹과 네이티브 저장 구현은 수정하지 않는다. 새 백업을 구버전 앱에 가져오지 않는다.

검증: JavaScript 217개, 웹/모바일 빌드, Chromium 320·390·800px의 화면 설정 변경·재열기·구버전 백업 가져오기·새 백업 복원·오프라인 저장·명식표 표시·초기화 18개 확인. 추가 회귀는 PR CI에서 실행한다. 물리 Android 기기에서 설치·한글 글꼴·SQLite 유지 검증은 별도다.

Android 패키지는 `com.newwonwoo.saju`, versionCode 15, versionName 1.1.5다. 공개 CI에는 개인 자료와 키가 없는 미서명 release만 내보내고, 개인 업데이트 APK는 기존 인증서와 같은 키로 비공개 환경에서 서명한다.

이 변경은 화면 설정 범위다. 운세 트리·격국·용신·궁합 등 나머지 기능 전체가 완료되었다는 의미는 아니다.
