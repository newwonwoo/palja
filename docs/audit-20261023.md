# 반복 전수점검 및 독립 브라우저 검증 — 2026-10-23

사용자 요청에 따라 다른 에이전트가 별도 IndexedDB와 합성자료로 독립 탐색하고, 수정본을 다시 검증했다. 실제 배포 주소는 Browser/CUA 연결 부재와 네트워크 CONNECT 403으로 직접 조작하지 못했다. 배포 정적 파일을 로컬 Chromium에서 실행한 결과이며 로그인한 배포 사이트 직접 테스트 통과라는 뜻이 아니다. [독립 재검증](independent-audit-20261023.md).

## 발견 및 수정

- 이름·메모만 바꿔도 미확인 역법이 양력으로 확정되던 문제: 날짜·간지 폼의 출생정보와 전체 수정 이력을 그대로 보존.
- 뒤로가기·입력 방식 변경 시 초안이 사라지던 문제: 계속 작성/저장하지 않고 이동과 페이지 이탈 보호 추가.
- 시작 실패 팝업을 닫으면 복구 버튼이 없어지던 문제: 실패 상태와 재시도 유지, 응답 복구 후 저장자료 정상 로드.
- 성별·나이 필터가 미분류로 표시되던 문제: 필터 결과와 실제 미분류 구분.
- 긴 이름 PNG가 명식표와 겹치던 문제: 이름 줄수에 따라 캔버스와 표 위치 확장.
- 숫자 생년월일은 있지만 원문 날짜가 없는 PNG의 미확인 표시: 유효한 숫자 날짜로 대체. 실제 날짜 없는 자료는 미확인 유지.

앞 네 항목은 독립 에이전트가 발견했고 PNG 겹침은 주 에이전트가, PNG 날짜는 독립 에이전트가 추가 발견했다. 여섯 항목 모두 수정 및 독립 재확인 완료.
