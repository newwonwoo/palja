# 전수점검 재개 및 대운 연경계 보완 — 2026-10-22

## 결과와 공정률

이전 조사에서 남겨 둔 **모바일 기본 계산 경로의 연초·연말 대운 공백을 수정**했다. 개인자료 163개를 소유자가 확인한 색상 성별 기준으로 계산했으며, 대운 생성은 **120개에서 123개**로 증가했다. 나머지는 출생시각 모름 39개 및 날짜·시각 누락 1개로, 추정값을 넣지 않았다. 원본 일주와 기본 양력 계산의 불일치 14개는 역법·보정 확인 대상으로 유지했다.

`engine.daewoon`의 결과 게이트를 다시 통과 처리했다. 코드 구현 **78/79(98.7%)**, 7개 게이트 전체 검증 **78/79(98.7%)**, 개별 게이트 **547/553(98.9%)**다. 직전 77/79에서 각 1개·1.2%p 증가했다. 남은 부분 구현은 원래 서명 APK의 실제 기기 업데이트/DB 보존 `data.upgrade`이다.

## 수정한 계산 계약

- 고정된 원본 `src/App.jsx` 및 네이티브 6개 파일은 수정하지 않았다. 모바일 어댑터가 기존 `calcDaeun`의 **빈 결과에만** 보완 계산을 적용한다. 정상 출력되는 기존 대운은 그대로 반환한다.
- 출생 전후 1개 연도를 포함한 독립 태양 황경 절기에서 순행의 다음 절 또는 역행의 이전 절을 찾는다. 중기는 제외한다.
- 기본 산식의 날짜 기준을 유지한다: 입력 생일의 정수 Julian day, 즉 **UTC 정오**를 기준으로 일수/3을 반올림하고 8개 대운을 만든다. 시각을 반영하는 정밀 기산으로 바꾸었다고 주장하지 않는다. 출생시각 미상·성별 미확인·날짜 누락은 계속 보류한다.
- 원국 4주·신강약·조후·용신·원본 출생정보·메모·DB는 바꾸지 않는다. 기존 역법에서 독립 정밀 역법으로 저장 정책을 자동 전환하지 않는다.
- 보완된 결과에는 방향·절입 경계·경과일·기산 기준을 연결했다. 명식 화면에 연경계 보완 적용을 표시하고 기존 기산 근거에서 자세히 확인할 수 있다.
- 별도 독립 절입 엔진의 10대운 및 기산 방법 선택은 그대로 유지한다. 기본 엔진의 8대운과 독립 엔진의 10대운을 구분한다.

- 원본 8자어때와 산식 전체의 동일성이나 명리 해석의 예측 정확도를 보증하지 않는다. 기본 역법의 날짜 기준·음력 자료·연도 범위 등 나머지 한계는 기존 문서와 같다.
