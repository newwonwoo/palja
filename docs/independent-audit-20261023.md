## PNG 추가 확인

부모 측 수정인 긴 이름 PNG도 별도로 확인했다. 합성 이름 180자의 내보내기에서 PNG 크기는 1200×930에서 **1200×1092**로 늘었다. 실제 이미지를 확인해 이름 줄과 명식표가 겹치지 않고 모두 읽히는 것을 확인했다.
