# 원본 APK 기반 화면 연결 보완

2026-10-20. 원본은 해시 검증된 8자어때 18.2.8의 ARM64 AOT 분석이다. 실제 원본 앱 화면 대조는 Android 시스템 오류로 미완료이며, 아래 정적 근거와 Palja 자체 조작 검증을 구분한다.

## 목록에서 궁합 직접 비교 (`match.select`)

원본 `SelectedMatchProfileNotifier.toggleProfile` (`0xc1f458`)은 기준 슬롯을 먼저 확인하고, 기준이 비었으면 채우며, 나머지 선택은 상대 슬롯을 교체하거나 해제한다. `clearBasisProfile` (`0xc1585c`)은 상대 슬롯을 유지한다. `setBasisProfile` (`0xc155c0`)은 같은 인물이 상대에도 있으면 중복을 제거한다. `MatchSelectScreen`의 확인 흐름 `0xc1dec4`~`0xc1df28`은 `mine`·`partner` 두 명식을 `match` 경로에 전달한다.

- [x] 세 번째 인물 선택 시 기준 명식을 밀어내던 동작을 고침. 두 슬롯을 명시적으로 유지.
- [x] 한 슬롯이 비면 확인 불가. 두 명식 선택 후 ‘궁합 확인’으로 두 명식표와 기존 독립 관계 분석을 바로 표시.
- [x] 선택한 상대를 화면 경로에 유지해 재실행 시 복구. 상대 변경은 현재 경로를 교체해 뒤로가기에 불필요한 단계를 만들지 않음.
- [x] 삭제·중복·미확인 명식 처리, 기준 슬롯 해제·재선택, 원본 레코드 보존 확인.
- [x] 브라우저 점검 19개 통과. 320/390/800px, 실제 두 카드·상대 선택값·뒤로가기·새로고침·미확인 일주 설명을 확인.
- [ ] 원본 실제 화면의 선택 표시·배치와 궁합 상세 전체 대조. 궁합 점수·튜닝은 이 변경에 포함하지 않음.

원본 확인 흐름에는 광고 표시 결과를 기다리는 별도 분기도 있다. Palja의 개인용 오프라인 범위에는 광고 호출을 추가하지 않았다. 원본 전체 화면 전이와 같다고 판정하지 않는다.

## 오늘의 운 복귀 (`reader.current`)

원본 `WoonsePresetButton._onTapTodayButton` (`0xcb9584`)은 현재 현지 `DateTime`을 만들고 `SelectedLuckType.day` (`c3e771`)와 함께 `updateWoonseContext`를 호출한다 (`0xcb95e0`~`0xcb9624`). ‘오늘로 돌아가기’ 문자열은 `0xcb8d14`에서 확인했다.

- [x] 명식 화면과 운세 화면에 ‘오늘로 돌아가기’ 연결.
- [x] 누른 시점의 기기 현지 날짜·시각을 선택하고 저장. 연도·선택운·폼을 함께 갱신하며 출생정보를 바꾸지 않음.
- [x] 오프라인 저장·재실행, 한국 시간대 자정/새해 경계, 기존 선택일에서의 복귀 확인.
- [x] 지원 범위 1900~2050년 밖에서는 날짜를 임의로 잘라 맞추지 않고 저장 전에 중단.
- [x] 브라우저 점검 16개 통과. 명식·메모는 그대로 보존.
- [x] 후속 묶음에서 일/월/년 조회 유형과 메모·즐겨찾기 저장 연결. [후속 기록](original-apk-batch-navigation.md).
- [ ] 원본 전체 분석 영향·시각 정규화·대운/세운 계산값과 실제 화면 대조.

## 풀이 탭 순서 (`settings.order`)

원본 `ExplanationTabReorderSheet`는 ‘분석·사주·운세·궁합’ 4개 항목을 재배열하고 취소/확인으로 처리한다 (`0x9afa1c`~`0x9afa48`, 확인 `0x9af6f0`). `ExplanationTabNotifier.applyTabOrder` (`0x9b04c4`)는 선택한 탭 유형을 유지하면서 정렬 상태를 적용하고 `_persistTabOrder`를 호출한다. 저장 키 `explanation_tab_order_v1`과 기본 객체 풀 `0x2de58`의 4개 enum 순서를 확인했다.

- [x] 같은 4개 풀이 탭의 순서를 저장하고 실제 탭 배치에 적용.
- [x] 확인 전에는 임시 순서만 변경. 취소·Escape는 저장하지 않으며 기본 순서 복귀도 확인 후 저장.
- [x] 재열기·백업·복원·오프라인 저장, 구버전 백업의 기본값·읽기 시 무변경 확인.
- [x] 표시 순서대로 방향키·Home·End 탐색. 탭 키를 유지해 화면 내용과 탭 선택을 잘못 연결하지 않음.
- [x] 브라우저 점검 21개 통과. 320/390/800px와 백업 복원을 확인.
- [ ] 원본 드래그 재정렬과 실제 배치 대조. 현재는 키보드·터치 조작이 가능한 위/아래 버튼을 사용.
- [x] 후속 묶음에서 프로필 배너 3종 순서/표시와 현재·생일자 경로 연결. [후속 근거와 한계](original-apk-batch-navigation.md).

## 검증

- JS 전체 244개 통과. 새 단위 테스트는 두 슬롯 전이, 현재 시각 선택·범위 차단, 탭 순서 검증·백업 보존을 확인한다.
- 새 화면 점검 56개와 기존 디자인 점검 18개 통과. Browser plugin not available로 설치된 Playwright Chromium 사용. 검사 URL은 `http://127.0.0.1:8851/`.
- 화면 식별·빈 화면·오류 오버레이·콘솔 오류·실제 조작 후 상태를 확인. QA 스크립트·결과·캡처는 `/tmp/palja-match-flow-qa/`, `/tmp/palja-today-flow-qa/`, `/tmp/palja-reading-order-qa/`에 보관.
- 웹·모바일 빌드, 기존 라이선스 읽기 전용 검사 후 오프라인 Android 단위 테스트·debug 빌드를 수행. 실기기 업데이트/원본 UI 실행 대조는 별도다.
