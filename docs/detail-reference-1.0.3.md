# 상세 화면 레퍼런스 반영 — 1.0.3

## 기준과 변경 범위
사용자가 제공한 상세 화면 5장(명식표, 오행 분석, 분석 요약, 합충 연결선, 신살 표)을 기준으로 기존 4열 상세 화면을 교체했다. 스크린샷의 개인정보와 원본 앱 자산은 이 저장소에 포함하지 않았다. 1.0.2에서 추측한 레이아웃이 아니라 실제 제공 화면의 시각 구조를 사용하되, 계산되지 않는 값을 복사해서 사실처럼 보이게 하지 않는다.

- `세운 / 대운 / 시주 / 일주 / 월주 / 연주` 6열과 오행색 둥근 글자판.
- 대운·세운·월운 가로 목록. 대운·연도 선택은 6열 명식표와 조후·합충·신살의 선택운 문맥에 연결된다. 월 선택은 해당 월 간지 안내까지이며 6열에 월운 열을 추가하지 않는다.
- 풀이 상단 `분석 / 사주 / 운세 / 궁합`, 하단 `명식 / 풀이 / 추가 / 메모 / 관리`, 초록색 명식 복귀 버튼.
- 원국 오행 원형도, 생·극 화살표, 기존 한난·조습 지수, 용신 근거 설명.
- 천간·지지 합충 선을 누르면 해당 글자 강조. 합/충형 필터와 선택운 포함/제외.
- 십이신살 6열, 일/년 기준 전환. 원국 관계와 선택운을 구분한다.
- 출생정보 편집·메모 저장·백업·휴지통으로 기존 기능 연결. 앱 내 다른 화면으로 나갈 때 미저장 메모 경고.

## 계산과 데이터 보존
`src/App.jsx`와 네이티브 SQLite/저장소 코드는 수정하지 않았다. 새 `reader-model.js`는 기존 결과를 화면에 연결하는 어댑터다. 조습 지수의 비공개 함수는 기존 산식 그대로 노출하기 위해 같은 연산을 별도 함수로 옮기고 29개 날짜 및 선택운 조합에서 수치 회귀 비교했다.

십이신살은 **별도로 명시한 조견표**이다. 삼합 그룹의 겁살 시작점부터 12지지 순서로 겁살·재살·천살·지살·년살·월살·망신·장성·반안·역마·육해·화개를 배치한다. 참고는 [점친당 자체 만세력 엔진 설명](https://jumchindang.com/wiki/십이신살)이다. 8자어때 Dart AOT에서 복원한 산식이라고 주장하지 않는다. 길흉살은 기존 천을귀인·양인·백호·괴강·원진 5종의 기준을 사용한다.

원본과 값이 다른 경우를 임의 보정하지 않는다. 예시에서 대운 시작 나이는 기존 엔진 38세와 원본 화면 39세가 달랐다. 기존 대운 반환은 8개인 반면 원본 화면에는 10개가 있었으며, 누락을 가짜 기둥으로 채우지 않았다. 명식 원본, 성별·달력·시간 미확인 상태와 기존 개인 자료는 그대로 유지한다.

## 아직 원본과 같지 않은 것
- 오행 비중·합화 가중치·격국·추가 신살, 천간극·자형 등 미연결 규칙.
- 첫 3개 비중 버튼은 **계산 기준 안내**이며 편집기가 아니다. 선택운 토글은 조후·관계표에만 영향을 주고 오행 원형도·신강약·용신은 원국 기준이다.
- 원본과 오행 점수/대운 기산 등 계산 동일성은 검증하지 않았다.
- 월운은 각 월 15일을 기존 월주 함수에 넣은 대표값이다. 정확한 절입 시각이나 해당 월의 운세 해석을 복원한 것이 아니다. 1월은 다음 해이며 그 연도를 명시한다.
- 원본의 운세 문장은 복사하지 않는다. 관계 조합 설명과 범위를 표시한다.
- 두 명식 비교에는 원본 궁합 점수/해석이 없다.
- 화면 설정은 현재 화면 세션에 적용한다. Android 시스템 뒤로가기/종료에 따른 미저장 입력 보존은 별도 실기기 검증이 필요하다.

## 실제 검증
- Node 테스트 **83개 통과**(기존 66 + 신규 표시/회귀 17).
- 기존 웹과 모바일 프로덕션 빌드 성공.
- 직접 사용할 브라우저 플러그인이 없어 별도 Playwright 1.51.1 / Chromium 134로 실제 정적 프로덕션 페이지를 검증했다.
- 실제 브라우저 20개 점검: 첫 화면, 6열, 실제 대운 수, 연도/대운/월 선택, 명식 팝업, 오행·비중 안내, 선택운 연동, 탭 키보드 이동, 관계 강조, 신살 기준, 두 명식 비교, 메모 저장/이탈 경고, 미상값, 반응형 화면, 큰 운 목록, 출생정보 불변, 로드 후 오프라인 조작, 오류/외부 요청 검사.
- 320/360/390/800px에서 문서 가로 넘침 없음. 큰 운 목록은 내부 가로 스크롤로 제공한다.
- 페이지 오류·콘솔 오류·외부 요청 **0개**. 로컬 HTTP 자산 요청은 외부 요청이 아니다. 브라우저 최초 오프라인 로딩 검증은 아니다.
- APK는 CI에서 개인 정보 없이 빌드하고, 사용자용 초기 자료/기존 서명은 별도 비공개 로컬 패키징에서만 사용한다.
- Android 실기기 설치/업그레이드/키보드/시스템 파일 선택기는 미검증이다.

## 코드 구성
`ReferenceReader.jsx`는 화면/선택 상태, `ReaderTiles.jsx`는 명식표/운 목록, `ReaderAnalysis.jsx`는 도식/관계/신살, `reader-model.js`는 순수 읽기 어댑터, `reference-reader.css`는 레퍼런스 스타일이다. 전체 변경은 `codex/8ja-detail-reference`에 있으며 main은 변경하지 않는다.
