# 8자어때 명식 보관함 UI·UX 비교 — 1차

기준: 사용자 제공 8자어때 18.2.8의 **친구 보관함 연속 스크롤 스크린샷 19장** (2026-10-11 촬영). 이번에는 사용자가 제공하지 않은 상세 명식 화면을 추정 복제하지 않았다.

## 원본 화면에서 확인한 디자인 계약

- 밝은 흰색 목록 바탕, 차분한 청회색 텍스트와 얇은 섹션 구분선.
- 상단 오른쪽: 명식 추가, 관리. 그 아래 회청색 띠에 `커스텀`, `궁합 모드`, `설정`의 세 개 아이콘 버튼.
- `친구 / 최근 입력` 세그먼트, 검색 입력, `가나다순` 정렬.
- `me` → `즐겨찾기 (7)` → `친구 (156)` 섹션, 나이 배지(청록/분홍)와 두 글자로 쌓은 일주 배지, 이름·입력 날짜·시각 및 별표.
- 전체 목록은 상단 조작 영역을 유지하면서 스크롤할 수 있음. 원본 사진에 없는 계산 상세·설정 화면은 이번 비교 범위 밖.

## 구현

- `src/mobile/ReferenceVault.jsx`: 기준 사진과 같은 화면 계층/섹션/행, 상단 바로가기와 목록 모드, 즐겨찾기 전환.
- `src/mobile/reference-vault.css`: 모바일 폭 기준 헤더, 아이콘, 행 높이, 오행별 글자 배지의 스타일. 외부 앱 자산·폰트는 복사하지 않음.
- `src/mobile/list-utils.js`: 원문 출생 정보 보존, 화면 나이 배지(미확인 역법에서는 원본 사진의 나이 유지), 일주 검색, 이름·날짜·나이 검색과 가나다/추가/나이/일주 정렬.
- **UX 개선:** 긴 친구 목록에서 상단 검색 영역 고정, 지우기 버튼, 빈 결과 설명, 좁은 간격 보기, 2인 선택 후 잘못된 궁합 점수를 만들지 않고 상세 확인으로 연결, 44px 전후의 터치 목표.
- 계산 엔진과 SQLite/백업 모델, 기존 저장 구조와 엔트리 ID, Android 앱 ID는 변경하지 않음.

## 검증

- 기존 JavaScript 55개 + 신규 6개 = **61개 통과**.
- 개인 출생자료를 공개 저장소로 보내지 않고 사설 개발 환경에만 임시 로딩하여 브라우저 UI를 실행함.
- **360px·390px·800px**: 횡스크롤 없음, me 1개, 즐겨찾기 7개, 친구 156개; 검색(이름·생년월일·나이·일주), 즐겨찾기 변경, 최근 입력, 목록 간격 설정, 2인 선택이 동작함. 브라우저 페이지 오류 0개.
- Android 폰의 실제 설치·뒤로가기·키보드 동작은 아직 검증 전. 기기에서 접근성/글자 확대 테스트 필요.

## 관찰된 개선점과 미완성 기능

1. **중요: 원본 리스트 유사도 우선.** 생년월일시 및 일주 라벨을 원문 그대로 보여 주되 계산이 확인되지 않은 항목을 사용자에게 표시.
2. **나이 의미:** 원본 사진의 나이 배지는 화면 촬영일 기준 표시값일 수 있음. 역법이 미확인인 항목은 원본 숫자를 유지하고 정확한 현재 나이라고 주장하지 않음. 양력을 명시적으로 확인한 명식만 오늘 기준 나이를 계산.
3. **보정 정보:** 원본의 `(-3' -13')` 등의 문자열은 임의 시각 보정으로 변환하지 않음.
4. **궁합 모드:** 현재는 2인 선택/명식 확인 단계. 실제 궁합 계산 자동 연결·점수 표현은 미완성으로 남김.
5. **커스텀:** 1차는 목록 밀도만 제어하며, 친구 그룹·사용자 지정 카테고리·고급 필터는 후속.
6. **상세 명식 UI:** 원본 화면 참고 스크린샷이 없어 현재 계산 결과 화면의 어두운 기존 레이아웃을 유지함. 원본 상세 화면을 확보한 다음 스타일과 인터랙션을 비교할 것.
7. **네이티브 UI 런타임:** 실제 기기의 상태바, Android 뒤로가기, 글꼴 배율, 시스템 파일 피커 등은 브라우저 검증과 별도로 확인해야 함.

## 개인정보 및 저작권

- 원본 스크린샷/명식 이름·생년월일/원본 APK, 개인 서명키를 GitHub에 업로드하지 않음.
- UI는 제공된 화면을 참고해 일반 React와 독립 SVG/CSS로 새로 구현함. 원본 상표·리소스·코드 파일을 복사하지 않음.
- 신상 정보를 포함한 스크린샷 비교 이미지는 비공개 작업 환경에서만 보관함.
