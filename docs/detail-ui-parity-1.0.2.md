# 8자어때 참고 상세 명식·분석 화면 — 1.0.2

## 범위
사용자가 제공한 8자어때 18.2.8 APK 및 **보관함 목록 스크린샷 19장**을 참고했다. 이 스크린샷은 명식 목록의 폰트 크기·구획·색상을 확인한 자료다. **8자어때의 상세 명식 화면 캡처는 제공되지 않았다.** 상세 화면의 픽셀 단위 복제라고 주장하지 않으며, 목록 화면의 시각 언어를 확장한 자체 구현이다.

## 구현
- `src/mobile/ReferenceDetail.jsx`, `reference-detail.css`: 청회색/흰색 상세 UI, 시·일·월·년 4열 명식표, 천간/지지 오행색, 십성·지장간, 원본/계산 결과 분리.
- 상단 액션: 즐겨찾기, 출생정보 수정, 내 명식 지정.
- 탭: 명식표 / 해석·대운 / 메모·관리. 오행·억부·조후·통관 및 대운, 원본 기록 확인, 소프트 삭제·복원 기능으로 연결.
- `detail-view-model.js`: 미상 시각의 시주 미표시, 날짜/보정이 미확인일 때 원본 일주만 유지, 계산값과 원본 일주 차이 경고, 유효하지 않은 오행 점수 보호.
- 원래 사이트의 고급 계산/해석 페이지는 별도로 접근할 수 있게 유지한다. 해당 페이지의 기존 세부 스타일은 이번 범위 밖이다.
- 모바일 기타 편집/설정 페이지도 밝은 색상으로 정리; 앱 버전 표시 1.0.2.

## 검증
- 전체 JavaScript 테스트 **66개 통과**(61 기존 + 표시 로직 신규 5).
- 모바일/원래 웹 프로덕션 빌드 성공.
- 합성 데이터만으로 구성한 브라우저 미리보기: **360/390/800px 모두 가로 넘침 없음**, 콘솔/페이지 오류 없음.
- 원래 Android 클래스/SQLite 구현은 수정하지 않았다. Java/Robolectric 15개 기존 테스트를 포함한 [GitHub Actions](https://github.com/newwonwoo/saju/actions/runs/38182734164) 성공.
- 사용자가 제공한 8자어때 APK, 스크린샷, 개인 명식/서명키는 공개 저장소에 포함하지 않았다.

## 배포 및 주의
- 개인용 APK 1.0.2(버전 코드 3)로 기존 1.0.1(버전 코드 2) 위에 업데이트 가능하게 구성. 두 버전 패키지 `com.newwonwoo.saju` 동일, 서명 인증서 SHA-256 동일.
- 기존 앱 삭제 전에는 개인 JSON을 따로 백업해야 하며, 가능한 한 기존 앱을 **삭제하지 않고 업데이트**한다.
- Android **실기기 설치 검증은 아직 없음**.
- **8자어때 계산식 동일성은 미검증**: 특히 절입 시각·균시차·역사적 한국 표준시·서머타임·야자시 조자시 및 연말 대운 근사값은 기존 계산 엔진의 한계로 남아 있다.

## 후속 개선 후보
상세 화면 원본 캡처와 실기기 피드백을 확보해 (1) 모션·스크롤, (2) 실시간 선택 상세, (3) 8자어때 명식 동작 비교를 단계적으로 개선. 계산 정확성은 모듈 이름만을 근거로 단정하지 말고 반례/경계 날짜 중심으로 재검증.
