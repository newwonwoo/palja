# 전체 기능 및 개인자료 전수조사 — 2026-10-22

> 최신 후속 상태: [재점검·대운 경계 수정](audit-resumed-20261022.md)에서 기본 모바일 경로의 3개 대운 공백을 수정·검증했다. 대운은 123개 생성되며 코드/전체 게이트 검증은 78/79(98.7%)로 복구했다. 아래의 77/79 및 미해결 연경계 판정은 **수정 전 최초 전수조사 기록**이다.

> 후속 자료 확인: 소유자가 원본 색상의 성별 의미를 확인한 뒤 별도 비공개 설정으로 남성 86개·여성 77개를 적용했다. 신규 시드 및 이미 저장된 동일 출처의 미확인 값에 적용하며 원본은 보존한다. 적용 후 기본 대운 생성 120개, 연경계 공백 3개, 시각 모름 39개, 날짜·시각 누락 1개다. 아래 표의 성별 미확인 163개와 가상 성별 시나리오는 **확인 전 전수조사 시점**의 결과다. 추가 테스트 4개를 포함한 전체 304개와 신규/기존 브라우저 저장소 자동 적용·확정값/삭제/메모/원본 보존·재적용 무변경 검증이 통과했다. 기본 대운 경계 결함 및 실기기 업데이트의 완료 판정은 그대로 보류한다.

## 판정

등록된 79개 기능, 자동 테스트, 실제 브라우저 조작, Android 빌드 및 개인자료 163개의 화면을 조사했다. 조사한 실행 흐름에서 새 런타임 오류는 발견되지 않았으나 **전체 기능 정상 완료로 판정하지 않는다.** 기본 대운 엔진의 연경계 결함과 실제 기기 업데이트 검증이 남아 있다. 개인자료의 미확인 값은 프로그램 결함과 구분한다.

완료 기준을 기본 엔진의 실제 사용 흐름까지 적용해 `engine.daewoon`을 부분 구현으로 정정했다. 코드 구현 및 7개 게이트 전체 통과는 **77/79(97.5%)**, 개별 게이트는 **546/553(98.7%)**다. 이전 78/79(98.7%)보다 각각 1개, 1.2%p 낮다. 코드를 삭제한 것이 아니라 완료 판정을 정정한 것이다.

## 검증 환경과 한계

- 로컬 브라우저: 기존 Playwright/Chromium. 연결 Browser `js` 및 CUA 도구가 제공되지 않아 기존 프로젝트 QA 경로를 사용했다.
- 개인자료 전수는 390×844의 별도 로컬 IndexedDB에서 수행했다. 원본 파일, 사용자 실제 브라우저 저장소, 배포 사이트의 DB를 수정하지 않았으며 개인자료 스크린샷은 만들지 않았다.
- 기존 시나리오는 320/390/800 및 데스크톱 뷰포트 등 각 스크립트의 정의에 따라 실행했다. 978개 전수는 모두 390×844이다.
- 오프라인 검증은 자산 로드 후 네트워크를 끊고 계산·저장·백업을 조작한 범위다. 웹 주소의 첫 접속/새로고침까지 오프라인 캐시가 제공된다는 뜻은 아니다. Android는 번들 자산을 사용한다.
- 실제 배포 주소를 사용자 로그인 세션으로 조작한 검증, Safari/WebKit, Android 실기기 설치·내보내기/사진 선택은 이번 실행 범위 밖이다.
- 원본 8자어때 계산과 모든 규칙의 동일성, 명리 해석의 예측 정확도를 검증한 것이 아니다. 독립 엔진의 근사값·연도 범위·설명 규칙은 기존 문서의 한계를 따른다.

## 재현과 증거

실행 로그와 JSON 결과는 `/workspace/palja-audit-20261022/`에 보관했다. 공개 저장소에는 개인 이름·생일·원본 JSON·DB·사용자 자료 화면을 넣지 않는다. 핵심 결과 파일은 `personal-data-summary.json`, `source-comparison-summary.json`, `personal-ui-results.json`, `unit.log`, `android.log` 및 각 브라우저 묶음의 결과 JSON이다.

전체 회귀는 `npm test`, `npm run build`, `npm run build:mobile`, `npx cap sync android`, Android의 `testDebugUnitTest assembleDebug assembleRelease`로 실행했다. 브라우저 7개 스크립트는 `.github/workflows/mobile-ci.yml`에 선언된 것과 같다. 개인자료 전수 스크립트는 로컬 전용이며 공개 CI에는 연결하지 않았다.

`npm run checklist:complete`는 두 미완료 항목이 해소될 때까지 실패해야 한다.
