## 실제 개인 업데이트 확인 절차

1. 기존 앱에서 전체 JSON 백업을 내보내 비공개 위치에 보관한다. 앱을 삭제하거나 저장소를 지우지 않는다.
2. unsigned release를 원래 개인키로 `scripts/sign-personal-update.sh`에서 서명한다. 이 도구는 패키지·원래 인증서·증가한 버전코드를 검사한다. 원래 개인키는 공개 저장소에 넣지 않는다.
3. 검증된 APK를 기존 앱 위에 업데이트하고 앱을 연다. 이름·생년월일·ID·즐겨찾기·그룹·메모·사진·그림·수정 이력·휴지통을 확인한다.
4. 아무 기록도 수정하지 않은 상태에서 새 전체 백업을 내보낸다.
5. `npm run upgrade:verify -- /비공개/설치전.json /비공개/설치후.json`으로 비교한다. 원래 항목의 삭제/변경은 실패한다. 추가 옵션은 허용하고 루트 revision/최근 열람 기록만 비교에서 제외한다. 출력에는 개인정보 값 대신 필드 경로·개수·파일 해시를 남긴다.
6. 실기기 결과가 확보된 후에만 개인 업데이트 검증 게이트를 완료한다. 현재 작업 환경에는 해당 실기기와 원래 개인키가 제공되지 않았다.

`npm run checklist:complete`는 모든 게이트가 통과할 때까지 실패해야 한다.
