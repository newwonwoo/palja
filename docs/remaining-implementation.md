## 현재도 검증 게이트가 남은 코드 구현 항목

코드가 있다는 이유로 전체 검증 완료로 올리지 않는다. 독립 후보 규칙의 한계는 [구현 기록](completion-20261020.md)에 명시한다. 특히 신강약/병약의 수치 문턱과 체·용·진신·가신은 선택한 연구 규칙의 계산이므로 전통 전체의 단일한 정답으로 검증했다고 적지 않는다.

완료 체크 명령은 미완료 상태에서 실패해야 한다:

```sh
npm run checklist:complete
```

## 다음 작업의 판단 기준

- 사용자는 원본 앱과 직접 산식을 대조하지 않고, 기존 계산기와 독립 엔진·공개 문헌·경계값으로 검증하도록 요청했다.
- 별도 학파·문헌이 지정되지 않으면 공개 고전과 조견표를 사용하며, 출처의 핵심 조건과 생략한 조건을 모두 드러낸다.
- 잘못 정의된 항목을 추측하여 완료로 바꾸지 않는다. `자오해사` 동작은 사용자 확인이 필요한 명세 공백이다.
- 실제 기기와 원래 개인키를 사용할 수 없는 상태에서 개인 업데이트/DB 보존 완료를 주장하지 않는다.
