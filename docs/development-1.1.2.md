# 개인용 오프라인 사주보관함 1.1.2 작업 기록

## 원칙
기존 명식과 저장된 출생 정보는 유지한다. 원본 8자어때와 직접 대조하지 않는다. 기존 계산기·독립 천문/시간대 엔진과 공개 조견표·경계 입력으로 검증한다. 사용자에게 결과를 확정적 길흉·운명 판정으로 제공하지 않는다.

## 이번 실제 기능
- 명식별 **운 선택 프리셋 30개**: 이름·날짜·시간 등록, 불러오기, 삭제, JSON 백업 병합 및 선택 내보내기 시 다른 사람의 프리셋 누출 방지. birth input은 불변.
- **5개 분야별 십성 분류와 12개월 대표 월운**: 재성/관성/식상/인성/비겁의 전통적 역할 설명, 월 15일 정오 산식의 실제 월간·월지·일지 관계. 월 클릭 시 선택일·시각을 저장. 정밀 절입 전후가 달라지는 점을 고지하며 재물 수익·승진·연애 확률 등 임의 점수 미제공.
- **명식 일괄 관리**: 활성 명식 다중 체크·검색 일괄선택, 그룹 배정/제외, 휴지통 이동 및 확인. 생년월일시와 메모를 수정하지 않음.
- **명식 PNG 내보내기**: 오프스크린 canvas에서 계산된 여섯 기둥과 확인 불가 글자를 구분해 이미지 생성. 별도 Android `exportImage` 파일 선택기로 네트워크 없이 PNG 저장. 원본 폰트·이미지 무단 복사 없음. 개인정보 노출을 사전 안내.

## 데이터 호환성
integrated namespace의 선택적 `presets` 필드 추가. 기존 `presets` 없는 v1 자료는 유효하다. 프리셋 이름 중복은 명식별로 거부, 최대 30개. 전체/선택 백업에 해당 명식의 프리셋 포함, 다른 사람의 프리셋 미포함. 수정 시 SQLite revision CAS 사용.

## 남은 항목
79개 범위 작업 중 미구현 9, 일부 구현 27. 격국·병약/희기구한 정밀 산식·합화/신살 규칙 차이, 분야별 복합 운세 해석, 전체 맞춤형 탭 배치, 원격 서버 의존 기능 등은 추가 연구와 검증이 필요하다. 현재 구현된 월운은 *월 15일 대표 샘플*이며 오행의 월별 점수/성과 예측이 아니다.

## 검증 기준
- `npm test`, `npm run build`, `npm run build:mobile`.
- 합성 데이터 Playwright 흐름: 명식 읽기→PNG 저장→운세 분야 필터→월운 적용→프리셋 저장/재열기→그룹 만들기→2명 일괄 배정→페이지 폭 320/360/390/800.
- Android Robolectric: PNG 서명 검증, 크기 제한, 파일명 정제, 기존 JSON/SQLite 테스트 통과.
- 개인 자료·서명키·원본 APK는 공개 GitHub 업로드 금지. GitHub에 올리는 APK는 개인정보 없는 개발 테스트판으로만 표시.
- 새로운 개인 APK는 **기존 개인용 서명키가 확인되기 전까지** 덮어쓰기 설치용으로 제공하지 않음. 기존 앱 삭제 금지.
