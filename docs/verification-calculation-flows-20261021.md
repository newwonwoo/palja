# 계산·분석·도구 잔여 검증

이 문서는 79개 추적 항목 중 기존 검증 33개를 제외한 **45개 기능의 독립 구현 계약**을 검증한다. 원본 8자어때의 내부 계산·문구·결과와 같은지 비교한 기록이 아니다. 모든 학파나 원본의 모든 미발견 기능을 포함한다는 뜻도 아니다.

## 제품 수정

- 출생시각 미상 처리에서 자정/23:59 두 시각만 계산하던 코드를 수정했다. 1948-06-01 서울처럼 자정이 DST 공백인 날짜는 명식 전체가 실패했다. 이제 해당 민간 날짜의 1,440분에서 존재하는 시각과 반복 시각 양쪽을 확인한다. 실제 순간과 보정 시각 각각의 범위 끝을 사용해 연·월·일주가 공통인 경우만 표시한다. 시주와 대운은 계속 비워 두며 출생정보를 변경하지 않는다. 전체 날짜가 존재하지 않으면 명시적으로 거부한다.
- 계산 근거에 시간대·전환표 버전, 보정 후 역법 시각, 반복 시각의 먼저/나중 선택을 추가했다. 실제 UTC 순간과 보정 후의 역법 시각을 구별한다.
- 브라우저 기본 favicon 누락(404)과 경로 이동 중 오프라인 재요청을 없애도록 자체 SVG 아이콘을 HTML data URI로 포함했다. 오류를 테스트에서 숨기지 않았다.

`scripts/generate-independent-reference.py`는 앱의 코드/표를 가져오지 않는다. Python 3.12, pyswisseph 2.10.3.2, korean-lunar-calendar 0.3.1, 시스템 IANA 2026b로 `tests/fixtures/independent-calendar.json`을 생성했다. 이 개발용 Python/Swiss 의존성은 앱에 포함하지 않는다. CI는 공개 숫자 fixture를 읽으므로 네트워크·추가 설치 없이 재현한다.

## 실행 환경과 남은 경계

현재 작업 공간의 Chromium/Playwright로 `http://127.0.0.1:8765/`를 실행했다. 연결된 사용자 브라우저 제어 도구는 제공되지 않아 기존 자동화 경로를 사용했다. 합성 데이터만 사용했다. 최초 자산 로드 후 네트워크를 끄고 모든 기능을 조작했다. 새로고침은 자산 로드 후 다시 오프라인으로 전환한다. 새 컨텍스트 가져오기 역시 자산 로드 후 오프라인이다. 서비스워커 없는 웹 브라우저의 완전한 오프라인 최초 실행을 검증한 것은 아니다. Android의 번들 자산/SQLite는 별도 JVM·빌드 회귀로 확인한다.

로컬 전체 회귀: JavaScript **300개**, 새 브라우저 **98검사/45기능**, 기존 브라우저 전체, JVM **21개**, 웹/모바일 생산 빌드, Android debug/release 빌드, 원래 계산/네이티브 7파일 SHA 고정 검사. 저장소 CI에서도 같은 브라우저 검사를 실행하고 합성 결과 JSON/화면을 artifact로 남긴다. 최종 CI 상태는 PR #6을 따른다.

원래 개인키와 실제 기존 설치 기기가 없으므로 `data.upgrade`의 비공개 서명·업데이트·실제 DB/첨부 보존은 완료하지 않았다. 모든 자동화/빌드 통과가 이 실기기 게이트의 대체는 아니다. `npm run checklist:complete`는 이 항목이 남아 실패해야 한다.
