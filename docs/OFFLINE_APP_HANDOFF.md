## 3. 사용자 요구 및 운영 원칙

1. **남은 사용자 기능 전부 구현**: 스크린샷 몇 장만 따라 그린 상태를 완료라고 하지 않는다.
2. **원본 8자어때와 기능·산식 직접 대조하지 않는다**(사용자 명시). 기존 계산기 엔진과 별도 독립 천문/역법 엔진을 교차검증한다. 역법/학파마다 다른 규칙은 근거와 선택 기준을 표시한다.
3. **기존 결과 회귀 금지**: 같은 입력에 대한 기존 4주, 명식 ID, 즐겨찾기, 그룹, 메모, 수정 이력, 최근 항목, 삭제·복원, SQLite 저장의 회귀 테스트. 의도적인 신규 계산 모드는 명시적 옵트인, 기존 기록 강제 변경 금지.
4. 오프라인 우선. 네트워크 의존, 로그인, 광고, 결제를 몰래 추가하지 않는다. 개인 자료·원본 앱 APK·서명키를 공개 저장소나 CI artifact에 포함하지 않는다.
5. 빈 껍데기 버튼, 임의 길흉 점수, 스크린샷과 무관한 모형은 완료로 세지 않는다.
6. 기능별 **입력→사용자 조작→계산 결과→저장→재열기/백업→오프라인→회귀 테스트**가 모두 통과해야 완료.
7. 새 개인 APK는 이전 서명 인증서와 동일해야 기존 설치 앱을 삭제하지 않고 업데이트된다. 버전 코드는 증가시킨다. 실제 기기에서 설치 테스트가 없다면 미검증이라고 명시한다.

## 4. 최신 완료 기준 / 알려진 한계

- 최신 통합된 소스 기준은 **1.1.2**, 원래 개발 HEAD는 `d4e8eb490147d634a45763177e140f1192893d4e` (PR #10).
- 1.1.2 CI: [테스트·빌드 성공](https://github.com/newwonwoo/saju/actions/runs/38345610594) (JavaScript **203개**, Chromium **13흐름**, Android **19개**). [최종 소스 내보내기 실행](https://github.com/newwonwoo/saju/actions/runs/38346533901) 성공.
- 원본 검증 기준은 `docs/full-feature-scope.json` + `docs/full-feature-scope.md`이며 79개는 *기능 분해 작업 단위*이지 원본 총기능 개수가 아니다. **2026-10-13 마지막 기록: 구현 43 / 일부 구현 27 / 미구현 9**. 각 세부 항목의 현행 코드를 반드시 다시 확인한다.
- 미완료 예시: 명리 격국/진신·가신/병약·용격의 독립 해석 및 근거, 신강약 근거 전체, 합화 적용 조건, 신살 체계 확장, 대운~시운 전 단계 운세 트리, 궁합 가중치·근거형 평가, 탭/배너 순서·색·글자 등 전체 디자인 설정, 공개명식/가져오기 등. 기능 상태표에서 실제 항목별 체크.
- 독립 역법은 Astronomy Engine 2.1.19 + korean-lunar-calendar 0.4.0 등 고정 의존성을 사용. 경계(절입, 야자시, 역사적 UTC offset/DST, 윤달)에서 기존 계산식과 차이가 나면 **차이를 설명**하고 과거 DB를 자동 재작성하지 않는다. 과거 1949년 시주 차이가 알려져 있다.
- 사진/그림 포함 전체 JSON 저장/백업 크기 상한 **8MiB**. 새 기능의 대용량 파일 처리는 저장/복원 실패 없이 검증.
- 실기기 업데이트/시스템 파일 선택기/비행기 모드에서의 새 실행은 **브라우저 자동검증과 별도**로 관리한다.

- 오프라인 앱 Android package: `com.newwonwoo.saju`
- 마지막 개인 업데이트 버전: **1.1.2 / versionCode 12**
- 이전에 확인된 개인 APK 서명 인증서 SHA-256: `76b0434edf1bde06e8b82b41eb8b40d380f06cb6d989827a4ce5c6506cabcd02` (지문만 저장. 실제 서명키는 **저장소에 없음**)
